# Home Assistant App: HA Alloy

![Supports aarch64 Architecture][aarch64-shield]
![Supports amd64 Architecture][amd64-shield]

Ships the Home Assistant OS journal (Core, Supervisor, apps, OS) to [Grafana Loki](https://grafana.com/oss/loki/)
with [Grafana Alloy](https://grafana.com/docs/alloy/latest/). Loads extra Alloy config from the app's config
folder and serves the Alloy UI through Ingress.

Options and labels: **Documentation** tab.
