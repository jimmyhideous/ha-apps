# Home Assistant App: Remote Terminal

![Supports aarch64 Architecture][aarch64-shield]
![Supports amd64 Architecture][amd64-shield]

A terminal in the Home Assistant sidebar that opens an SSH session on another host. It authenticates with its own
key and attaches a tmux session there, so the shell keeps running when the panel closes.

Options and setup: **Documentation** tab.
